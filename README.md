# CallMeMaybe

Introduction to function calling in LLMs

## Usage

```sh
export UV_CACHE_DIR=/tmp/uv/cache
export UV_TOOL_DIR=/tmp/uv/tools
export UV_TOOL_BIN_DIR=/tmp/uv/bin
export UV_PYTHON_INSTALL_DIR=/tmp/uv/python

uv add accelerate
uv sync
uv run titi.py
```
